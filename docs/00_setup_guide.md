# 00 — Reproducible setup guide

| item | version used | notes |

## 2. Install

```bash
cd <repo root>
python -m pip install -r requirements.txt
# optional: install the package itself so `import aan` works anywhere
python -m pip install -e .
```

The scripts also work without installation: they prepend `src/` and `scripts/`
to `sys.path` (`scripts/validate_build.py:22-25`).

## 3. Verify the environment (≈ 1 second)

```bash
python scripts/validate_build.py
```

Expected: `13/13 checks passed` and exit code 0. The suite covers config
loading/overrides, frame-wise conv equivalence, the attention formula, reference
attention semantics (including CFG broadcasting and mismatch errors), cross
attention identity, temporal zero-init identity, Pose Guider grid, ReferenceNet
bank ladder, both pose-fusion modes, the VAE round trip, an end-to-end
generation with mp4 export, and metric behaviour.

> A `FutureWarning: torch.utils._pytree._register_pytree_node is deprecated`
> message comes from `diffusers 0.24.0` and is harmless.

## 4. First run

```bash
python scripts/make_demo_inputs.py --out inputs/demo --frames 16 --size 256 --seed 7
python scripts/run_prototype.py --config configs/prototype_cpu_small.yaml --steps 6
```

Outputs land in `outputs/run_small/`: `video.mp4`, `contact_sheet.png`,
`shape_log.json`, `run_log.json`, `metrics.json`, `config_used.yaml`.
Runtime on the reference machine: ~0.83 s for 8 frames × 6 steps at 96×96, peak
RSS ≈ 385 MB.

## 5. Experiments

```bash
python scripts/run_ablations.py                      # all 19 configurations
python scripts/run_ablations.py --only E01 E04       # substring filter
python scripts/run_ablations.py --no-videos          # skip mp4 encoding
```

Outputs: `outputs/ablations/ablation_report.csv`, `ablation_report.md`,
`ablation_runs.json`, plus one mp4 per configuration.

## 6. GPU usage

```bash
python scripts/run_prototype.py --device cuda --dtype float16 --steps 30
```

* `--dtype float16` is the production default **on GPU**; on CPU it is
  pathological (E11: +1115 % runtime).
* For a real GPU run with real modules, switch the config:
  ```yaml
  vae:  {mode: pretrained, pretrained_id: stabilityai/sd-vae-ft-mse}
  clip: {mode: pretrained, pretrained_id: openai/clip-vit-base-patch32}
  unet: {context_dim: 512, base_channels: [32, 64, 64]}   # match the CLIP width
  ```
  and remember `config.validate_config` will refuse a mismatch between
  `clip.projection_dim` and `unet.context_dim`.
* Multi-GPU memory tools for the production pipeline:
  `enable_attention_slicing()`, `enable_vae_slicing()`,
  `enable_sequential_cpu_offload()` (all present in the reference pipeline).

## 8. Troubleshooting quick list

| symptom | fix |
|---|---|
| `ModuleNotFoundError: aan` | `pip install -e .` (or rely on the `sys.path` lines in the scripts) |
| mp4 export fails | ensure `imageio-ffmpeg` is installed; our writer sets `macro_block_size=None` for odd sizes |
| very slow runs | check you are not on `--dtype float16 --device cpu`; lower `--steps` or `--frames` |
| `frame count F exceeds temporal max_frames` | raise `motion.max_frames` (or shorten the clip) |
| different numbers after reinstall | compare `environment` in `run_log.json`; pin versions from `requirements.txt` |
